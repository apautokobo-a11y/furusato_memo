# ふるさと納税 寄附メモ v1.0(Python版 + HTML版)

自作ツール工房 P23「ふるさと納税 寄附メモ+ワンストップ期限リマインダー」です。
寄附を記録しておくと、起動直後に **いちばん急ぐこと**(例:「ワンストップ申請書 未送付 3件 → 1/10必着まで あと52日(投函目安 12/31)」)と、次の4つを大きく表示します。

| カード | 内容 |
|---|---|
| ○年の寄附 | 件数・合計金額・寄附先の団体数 |
| 上限の目安まで | 自分で入れた「上限の目安」まであといくらか(何%使ったか) |
| ワンストップ申請書 | 未送付の件数と「1/10必着まで あと○日」 |
| 寄附先 | ○/5団体(6団体以上になるとワンストップ特例は使えない) |

ほかに、月別の寄附グラフ(累計の線と上限の目安の線)、チェック一覧(上限超え、5団体の警告、確定申告が必要なときの受領証明書の確認、返礼品の未着など)、寄附一覧(期限・状態つき)があります。

> ※ 控除の上限額は計算しません。ポータルサイトのシミュレーターなどで自分で調べた金額を「上限の目安」として入れてください。税務の助言ではありません。
> ※ 起動直後のサンプルデータ(7件 ¥98,000 など)は**架空**です。

## Python版の使い方

1. Python 3.10以降で `python furusato_memo_v1.0.py`(exe化した場合は exe をダブルクリック)。
2. 最初はサンプル(架空)が表示されます。何か編集すると、**exeと同じフォルダ**に `furusato_memo_data.json` が作られて自動保存されます(サンプルのままでは保存しません。保存ファイルが壊れていたら `.broken` に名前を変えてサンプルで起動します)。
3. ボタン
   - **寄附を追加** / 表の行を**ダブルクリック**または**編集**: 日付・都道府県・自治体・返礼品・金額・申請書の状態・受領証明書・返礼品の到着・メモ
   - **メールから追加**: 寄附完了メールの本文を貼り付けて「読み取る」→ 日付・自治体・金額・返礼品が入った状態で追加画面が開きます(内容を確認してOK)
   - **申請書を送った**: 未送付 → 送付済み → 受理済み の順に進めます
   - **証明書が届いた** / **返礼品が届いた** / **削除**
   - **読込**: CSV または JSON
   - **書出**: CSV(Excel向け)/ JSON(バックアップ)/ カレンダー(.ics)/ レポート(.txt)
   - **設定**: 対象年(0=自動。1/10までは前の年)、基準日(空=今日)、上限の目安、投函目安(必着日の何日前、初期値10日=12/31)
   - **サンプルに戻す**: 保存ファイルを消してサンプルに戻します

### exe化

```
pip install pyinstaller
pyinstaller --onefile --noconsole furusato_memo_v1.0.py
```

外部通信・subprocessは使っていません。ウイルス対策ソフトの誤検知が出る場合は、配布前に VirusTotal で確認してください。
Windows の SmartScreen で「WindowsによってPCが保護されました」と出たら「詳細情報」→「実行」で起動できます。

## HTML版の使い方

1. `furusato_memo_v1.0.html` をダブルクリック(Chrome / Edge 推奨)。通信は一切しません。
2. 機能はPython版と同じです(同じサンプル・同じ計算結果・同じ書出ファイル)。
3. 保存はブラウザの localStorage(キー `furusato_memo_v1`)。シークレットモードなどで使えない場合も動きますが保存されないので、**書出 → JSON** でバックアップしてください。
4. 読込はファイル選択(CSV / JSON)、書出はダウンロードです。Python版で書き出したJSONをHTML版で読み込めます(逆も可)。
5. スマホ幅では表がカード表示になります。

## CSVの形式

```
日付,都道府県,自治体,返礼品,金額,申請,受領証明書,返礼品到着,メモ,ID
2026-02-14,北海道,紋別市,ホタテ 1kg,12000,受理済み,あり,到着済み,,F002
```

- 必須は **日付・自治体・金額**。見出しの別名も読めます(寄付日/寄附日、寄付先/市区町村、寄付金額、お礼の品 など)。
- 都道府県の列がなくても「北海道紋別市」のように書いてあれば分けて読みます。
- 申請: 未送付 / 送付済み / 受理済み / 確定申告(「済」「投函」なども読めます)
- 日付は 2026-11-19、2026/11/19、2026年11月19日、20261119、11/19(年なしは対象年)など。
- 文字コード: UTF-8 / UTF-8(BOM) / Shift_JIS。同じ寄附(日付・自治体・金額・返礼品が同じ)は飛ばします。

## カレンダー(.ics)

- 「○年分の寄附締切(12/31)」「ワンストップ申請書の投函目安」「申請書 必着日(1/10)」を終日の予定として書き出します。
- それぞれ **前日9:00** に通知が出る設定です(カレンダーアプリにより表示は異なります)。
- 確定申告が必要な状態(6団体以上など)のときは寄附締切だけを書き出します。

## 判定のルール(このツールの考え方)

- ワンストップ特例は「確定申告が不要な給与所得者等」で「1年間の寄附先が5団体以内」のときに使えます。同じ自治体への寄附は何回でも1団体と数えます。
- 申請書は寄附した翌年の1月10日必着。過ぎたら確定申告で控除を受けます。
- 1件でも「確定申告」にすると、ワンストップ申請は無効になるので、その年の寄附をすべて申告に入れるよう警告します。
- 制度の細かい条件は年によって変わることがあります。最終的には総務省・各自治体・ポータルサイトの案内を確認してください。
